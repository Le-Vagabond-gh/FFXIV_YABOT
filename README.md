## YABOT - Yet Another Bundle of Tweaks
*Separately we are tweaks, but together we form a mighty yabot!*

A bundle of small quality-of-life tweaks for FFXIV.

**Author:** Le Vagabond

## Installation
- Download `yabot-<version>-full.zip` from [Releases](https://github.com/Le-Vagabond-gh/FFXIV_YABOT/releases) and extract it to a folder of your choice - it contains the plugin and everything it needs to run
- Open the Dalamud Plugin Installer
- Go to Settings
- Head to the "Experimental" tab
- Under "Dev Plugin Locations", click "Select dev plugin DLL"
- Add the `yabot.dll` you extracted
- Press "Save and Close"
- in the main plugin installer window, enable the plugin in Dev Tools

To update later, `yabot.dll` and `yabot.json` are also attached to each release on their own - drop them over the ones you extracted and reload the plugin.

note: adding custom repositories to Dalamud is a security risk, this way protects you from malicious updates from untrusted sources

## Usage
Type `/yabot` in chat to open the configuration window.

Each tweak can be enabled or disabled independently from the configuration.
