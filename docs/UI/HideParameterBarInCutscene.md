# Hide Parameter Bar During Cutscenes

The game hides the HUD when a cutscene starts, but the parameter bar (HP/MP/GP/CP, top-right by default) stays on screen even though nothing you can do with it matters during a cutscene.

This feature hides the parameter bar while a cutscene is playing and puts it back when the cutscene ends - including scenes where the game briefly re-shows it on its own.

If the parameter bar is already hidden when a cutscene starts (HUD toggled off, or hidden in your HUD layout), it is left alone and stays hidden afterwards.
