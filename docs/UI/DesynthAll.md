# Desynth All

Adds two buttons next to the desynthesis window:

- `Desynth All`: desynths every item in the category currently selected in the dropdown
- `Desynth Inventory Equipment / Items + Housing`: desynths everything in Inventory: Equipment, then everything in Inventory: Items & Housing

Each button can be hidden on its own in the feature settings.

The desynthesis window closes on its own once the run is done. Click the button again while it runs to abort.

> [!WARNING]
> NOTHING IS FILTERED OUT. every item listed in the selected categories gets desynthed, including gear you might want to keep. move it to the armoury chest or a retainer first.

Doesn't run while mounted.
