# Auto-Confirm Discard

Hold Shift while clicking **Discard** in an item's right-click menu and the confirmation prompt is answered Yes for you. The same applies to **Lower Quality**, the entry that converts an HQ item to NQ.

Without Shift held, both prompts behave exactly as they normally do. Nothing else about the right-click menu changes, and no other yes/no prompt in the game is affected.

Shift is read at the moment you click the menu entry, not when the prompt appears, so releasing the key as the dialog opens doesn't matter. Only a prompt that follows directly from that click is confirmed - if the click somehow produces no prompt, the feature disarms itself rather than confirming whatever shows up next.

Both actions are destructive and neither is undoable, so the modifier is deliberately fixed to Shift and there is no option to skip the prompt unconditionally.
